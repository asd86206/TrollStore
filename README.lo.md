## 📖 TrollStore ແມ່ນຫຍັງ?

TrollStore ໃຊ້ຊ່ອງໂຫວ່ CoreTrust ເພື່ອເຊັນ ແລະ ຕິດຕັ້ງ IPA ໃດກໍໄດ້ຢ່າງຖາວອນ. ມັນບໍ່ແມ່ນ jailbreak. ແອັບທີ່ຕິດຕັ້ງແລ້ວຍັງຄົງຖືກເຊັນ ຈຶ່ງບໍ່ໝົດອາຍຸແບບ sideload ທຳມະດາ.
