# 🎭 TrollStore Installation Guide

**How to install TrollStore, which iOS versions it supports, and which method matches your chip.**

---

## 📖 What is TrollStore?

TrollStore uses the CoreTrust bug to permanently sign and install any IPA. It is not a jailbreak. Installed apps stay signed, so they do not expire the way a normal sideloaded app does.

### ✨ Core advantages

- ✅ **Free**: nothing to pay
- ✍️ **Permanent signing**: installed apps do not expire
- 📱 **Install on the device**: install an IPA directly on your iPhone
- 🔓 **No jailbreak**: the system is not jailbroken

### 📱 Supported versions

| Status | iOS version | Notes |
| :--- | :--- | :--- |
| 🟢 | iOS `14.0 beta 2` – `16.6.1`, `16.7 RC`, `17.0` | Supported |
| 🔴 | iOS `14.0 beta 1` and earlier | Unsupported |
| 🔴 | iOS `16.7` – `16.7.11` | Unsupported |
| 🔴 | iOS `17.0.1` and later | Unsupported |

> **💡 Tip**: Do not update iOS. A newer system version can move the phone off this list, and TrollStore cannot be installed after that.

`16.7 RC` (build 20H18) is supported. The final `16.7` release is not. The install-method table follows [Installing TrollStore](https://ios.cfw.guide/installing-trollstore), which also marks `16.7.12` – `16.7.16` as unsupported.
